# DP-MLM: Differentially Private Text Rewriting (Replication + New Data)

This notebook replicates **DP-MLM**, a differentially private text-rewriting method that uses a masked language model (RoBERTa). It then applies the method to new data: AG News subsets and a small synthetic PII dataset. Each word in a sentence is masked in turn, and a replacement is sampled from the model's clipped, temperature-scaled logits. That sampling step is the exponential mechanism, so a lower ε gives stronger privacy and more aggressive rewriting.

> Method reference: Meisenbacher, Chevli, Vladika & Matthes, *"DP-MLM: Differentially Private Text Rewriting Using Masked Language Models"*, Findings of ACL 2024.

### Core usage

``` python
dp = DPMLM(MODEL="roberta-base", alpha=0.003)

text, n_changed, n_total = dp.dpmlm_rewrite(
    "Apple is acquiring a startup to boost its AI capabilities.",
    epsilon=8,          # per-token privacy budget
    TEMP=True,          # DP sampling (exponential mechanism)
    FILTER=False,       # antonym filter (not applied in TEMP mode)
    CONCAT=False,       # True = feed original + masked sentence (slower, more context)
    REPLACE=False,      # True = feed already-rewritten tokens back in sequentially
    SKIP_STOPWORDS=True
)
```

**DP mechanism (TEMP=True):** logits are clipped to `[-3.21, 16.30]`, so sensitivity Δ ≈ 19.51. They are then divided by `2Δ/ε`, softmaxed, and a token is sampled from the result. Under sequential composition the **sentence-level budget is ε × (number of rewritten tokens)**.

## Known issues: read before presenting results

1.  **The extension section does not use DP-MLM.** The IMDB, "BBC" and ε ∈ {16, 8, 4} sweep cells call `rewrite()`, a keyword-synonym placeholder with no privacy guarantee. It changes only about 4% of IMDB rows. The BLEU 0.995 / ROUGE-L 0.998 values and the plot titled *"Privacy–Utility Trade-off (DP-MLM)"* therefore **do not describe DP-MLM**. Fix: replace `rewrite(t, epsilon=eps)` with `dp.dpmlm_rewrite(t, epsilon=eps, TEMP=True, CONCAT=False)[0]` (truncate long texts first).
2.  **TF-IDF cosine bug in `evaluate_rewrites`.** `cosine_similarity(orig, rew).mean()` averages the *full* N×N matrix, which is why the result is 0.026. Use `.diagonal().mean()`, as the §9 cell does.
3.  **The "BBC News" demo loads `ag_news`.** Either relabel it or load a real BBC dataset.
4.  **Duplicate WordNet helpers.** §3 redefines the functions from §1 and calls `en.synsets` directly, so the NLTK fallback breaks if OEWN is unavailable. Delete §3 or guard it with `if USE_OEWN`.
5.  **The model is loaded twice.** `distilroberta-base` is loaded, then immediately replaced by `roberta-base` in §8. Keep one. Also note that `similarity_score` hard-codes 12 layers × 12 heads, which is wrong for distilroberta (6 layers).
6.  **Some flags are ignored in TEMP mode.** `FILTER` and `ENGLISH` have no effect when `TEMP=True`, because filtering only runs on the top-K path.
7.  **Not fully reproducible.** Sampling uses `np.random.choice`. Seed with `np.random.seed(...)` before *every* run you report; §8 is currently unseeded.
8.  **Tokenizer artifacts.** Some outputs contain sub-word fragments (`ullivan`, `Itual`) and `�`, because RoBERTa BPE pieces are decoded as whole words. Restricting sampling to whole-word tokens (leading `Ġ`) would improve readability.
